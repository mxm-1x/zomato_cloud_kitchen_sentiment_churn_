# 📊 Bangalore Cloud Kitchen Sentiment & Churn Analytics Dashboard

This is a local backup of the dashboard verification and implementation report.

Please open the system generated artifact `zomato_dashboard_report.md` or review `reports/` folder directly to see the high resolution visual galleries and the interactive walk-through video!

## 🏃 How to Run the Dashboard

The dashboard server is currently **running live in the background** on your local machine at:
🔗 **[http://127.0.0.1:8050/](http://127.0.0.1:8050/)**

If you ever need to manually restart the dashboard in the future, navigate to the project root and run:
```bash
.venv/bin/python src/dashboard.py
```
